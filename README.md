# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VSCode

## Para testar

Para executar um exercício, abra o terminal do VS Code na pasta do projeto e digite:

```bash
python nome_arquivo.py
```

Substitua `nome_arquivo.py` pelo nome do arquivo que deseja executar.

Exemplos:

```bash
python hello.py
python soma.py
python condicional.py
python for.py
python exercicio1.py
```

Os demais exercícios podem ser executados da mesma forma.
